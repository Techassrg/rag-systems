# RAG Systems

Local, reproducible components for building retrieval augmented generation systems. Projects use synthetic incident documents, bounded inputs, deterministic behavior, and offline tests. No paid APIs or cloud services are required.

## Projects

- [Document Ingestion Pipeline](projects/document-ingestion-pipeline/README.md): validates Markdown and text input, normalizes content, and produces deterministic overlapping chunks.
- [Hybrid Retrieval API](projects/hybrid-retrieval-api/README.md): serves explainable BM25 and sparse TF-IDF cosine retrieval through FastAPI.
- Citation Aware RAG and RAG Regression Evaluation are planned for October 17.
